Root cause (debug of the node tree): parse_html preferred containers whose class/id matches CONTAINER_HINTS. The only hinted node with text was the group-blurb widget <div class="Content"> (31 words). The article container has classes "row margin-top-large"/"col-md-12" (no hint) so it was never considered. Second flaw: blocks of a node were listed before the blocks of nested tables, so tables moved to the end of the text.
Because no alternative form is needed, the ordered fallbacks (JSON-LD, embedded JSON, noscript, feed) were NOT implemented: nothing in Step A worked as a fallback, they would only add attack surface and extra requests.
